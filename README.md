# Rigly

### Local PHP development, without the overhead.

**Every PHP site on your computer, ready in seconds.**

Rigly is a native local development environment for **macOS and Windows**. Run PHP projects, manage databases, switch PHP versions, catch emails, inspect dumps and share your work — all from your menu bar or system tray.

No Docker. No virtual machines. No complicated configuration.

[**Website**](https://getrigly.com) · [**Documentation**](https://getrigly.com/docs) · [**Download Rigly**](https://getrigly.com)

---

### Everything you need. Nothing you don't.

- **Instant local sites** — Park a directory and get automatic `.test` domains, with HTTPS available in one click.
- **PHP 7.4–8.5** — Run multiple PHP versions side by side, with per-site configuration, Xdebug and profiling tools.
- **Databases & services** — MySQL, MariaDB, PostgreSQL, Redis, MongoDB, Meilisearch, MinIO and more.
- **Node.js & Composer** — Manage Node versions per project, with Composer and the Laravel installer included.
- **Mail & debugging** — Catch outgoing emails and inspect dumps, queries, jobs, logs and HTTP requests.
- **Public sharing** — Securely expose local sites through TunnelPad, with request inspection and replay.
- **Git workspaces** — Work on separate branches with independent sites and cloned databases.
- **CLI & team configuration** — Manage your environment with the `rigly` command and share project setup through `rigly.yml`.

### Your environment. Your workflow.

Rigly works with Laravel, WordPress and other PHP applications, without getting in your way.

```bash
# Serve every project in a directory
rigly park

# Enable local HTTPS
rigly secure

# Use a specific PHP version
rigly isolate 8.3

# Add a database
rigly service:add mysql

# Share your local site
rigly share
```

Use the native app, the command line, or both. They work together.

### Built to stay out of your way.

Rigly is built with **Swift on macOS** and **WinUI on Windows**. No Electron, containers or virtual machines.

It's self-contained, keeps your existing development tools untouched and is designed to feel like part of your operating system.
